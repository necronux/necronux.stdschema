    compositeRituals: Mapping<String, CompositeRitual>?

    The composite rituals in this grimoire associated with an identifier.

    It is advised to not use this composite ritual approach if the ritual does not have any spells and hexes from a linked grimoire. This composite ritual approach removes the limiting conformance of this grimoire's schema version for spells and hexes from other grimoires which may use different schema versions.

    Example:

    compositeRituals {
  ["example"] {
    new CompositeRitual { ... }
  }
}

    linkedGrimoires: Mapping<String, LinkedGrimoire>?
